# Omulimi — Project Memory

## Identity
- Current product name: Omulimi
- Previous product name: Farvo
- Omulimi is an agricultural technology platform for farmers and agricultural organizations in Uganda.

## Important Rebrand Rule
All new user-facing branding must use "Omulimi".
Do NOT blindly rename technical identifiers, database identifiers, URLs, migrations, or environment variables if doing so could break the application.

## Engineering Goal
Build a reliable, secure, mobile-friendly agricultural platform while preserving working functionality.

## Agent Rule
Before implementing major changes:
1. Inspect the existing code.
2. Understand how the relevant feature currently works.
3. Make the smallest safe change necessary.
4. Test the change.
5. Update project memory when architecture or decisions change.
